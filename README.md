# DEBOSS GLOBAL Admin

The Next.js operational console for DEBOSS GLOBAL.

## Setup

1. Copy `.env.local.example` to `.env.local`.
2. Set the Supabase URL and publishable key.
3. Set `NEXT_PUBLIC_API_URL=http://localhost:4000`.
4. Start with `npm run dev`.

The database migration and initial Super Admin setup are documented in the backend repository README.
